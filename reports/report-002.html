Summary

Implemented two factory presets targeting the Nord Drum 2 Desktop percussion synthesizer: one for the Korg nanoKONTROL2 (16 parameters) and one for the Akai MidiMix (32 parameters). The MidiMix preset required extending the preset schema to support DeviceMappingConfig, which was identified as recommendation #4 in Report #001.

The Nord Drum 2 uses a per-pad channel architecture (pads 1-6 on MIDI channels 1-6, global FX on channel 10). All CC assignments were verified against the official Nord Drum 2 MIDI implementation chart. A dedicated CC reference module provides type-safe constants for all 26 per-pad parameters and 6 global FX parameters.

The implementation was executed across 6 phases using 6 subagents, expanding the test suite from 320 to 356 tests with zero regressions. The preset count increased from 8 to 10.

Findings

Medium Preset Schema Extension — DeviceMappingConfig Union
src/shared/schemas.ts

The presetSchema.mapping field was changed from mappingConfigSchema to z.union([mappingConfigSchema, deviceMappingConfigSchema]). This required updating type narrowing in 8 downstream consumer files (ControlPopover, Track, Transport, EditorView, preset store, PresetList, EditControlValuesDialog, ipc-handlers) to handle the union type. Type guards isDeviceMappingConfig() and isMappingConfig() were added to discriminate the union at runtime.

Low Parameter Selection — Musical Priority for Limited Controls
src/shared/schemas.ts

The Nord Drum 2 exposes 26 per-pad CC parameters, but the nK2 can only map 2 per track (16 total). Parameters were selected by musical impact for live performance: Tone Spectra (CC 30) on knobs provides the most dramatic timbral sweep, while Tone Decay (CC 50) on sliders controls the most musically important envelope parameter. The MidiMix preset maps 4 per track (32 total) by adding Noise Filter Freq (CC 14) and Tone Timbre (CC 52).

Low Channel-Per-Pad Architecture — Multi-Channel Mapping
src/shared/nord-drum-2-cc.ts

Unlike generic MIDI presets which use a single channel, the Nord Drum 2 presets assign different MIDI channels to each track (channels 1-6 for pads, channel 10 for global FX). This is the first preset in nkEditor3 that uses the MappingEntry.channel field for per-control channel assignment rather than a global channel. The implementation validates that the nkEditor3 architecture correctly supports per-control channel routing.

Recommendations

  1. Hardware Testing — Test both presets with a physical Nord Drum 2 Desktop connected to verify CC assignments, channel routing, and parameter response. The CCs were verified against the official MIDI implementation chart but have not been validated end-to-end with hardware.
  2. Additional Target Synthesizers — The Nord Drum 2 CC reference module pattern (nord-drum-2-cc.ts) establishes a template for adding more synth-specific presets. Recommended candidates: Novation BassStation II, ASM Hydrasynth, Korg Minilogue XD, Moog Grandmother.
  3. DeviceMappingConfig UI Editor — The MidiMix Nord Drum 2 preset uses DeviceMappingConfig which is not yet fully supported by the UI editor. The MidiMixEditor component works with the nK2-shaped MappingConfig. A future enhancement should allow editing DeviceMappingConfig presets in the MidiMix editor, showing all 3 knob rows with their mapped labels.
  4. Preset Export/Import — As synth-specific presets accumulate, consider adding preset export/import functionality so users can share Nord Drum 2 or other synth mappings independently of the application.
  5. Parameter Expansion Presets — The nK2 Nord Drum 2 preset only maps 16 of 26 available per-pad parameters. Consider creating variant presets (e.g., "Nord Drum 2 Noise" focusing on noise section, "Nord Drum 2 Full" using channel-per-pad with multiple nK2 scenes).
